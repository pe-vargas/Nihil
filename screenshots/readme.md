# Pasta `screenshots/`

**NIHIL | Universidade Tuiuti do Paraná | 2026**

## Sobre a pasta

Reúne as capturas de tela exibidas no README principal do projeto.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| `home.png` | Página inicial com o hero e a vitrine do drop |
| `quiz.png` | Resultado do quiz com as peças recomendadas |
| `colecao.png` | Página de coleção (feminino ou masculino) |
| `carrinho.png` | Carrinho com itens e valor total |

## Como gerar as capturas

1. Executar o projeto com `php -S localhost:8000`;
2. Adicionar alguns produtos ao carrinho e concluir o quiz;
3. Com o navegador maximizado, capturar a tela (no Windows: `Win + Shift + S`);
4. Salvar em formato PNG nesta pasta, com os nomes da tabela acima.

---

**Observação:** O Git não armazena pastas vazias. Este arquivo garante que a pasta exista no repositório antes da inclusão das imagens.
